Methodology

This demo is based on the market-transparency study Increasing market transparency of residential air-to-water heat pumps in Europe by clustering the appliances by Ugne Potthoff, Felix Morlock, and Felix Wortmann, prepared for HPC2026.

Data basis

The underlying research links certified technical data from Heat Pump Library / Keymark records with web-scraped European online retail prices. The processed app dataset contains matched residential air-to-water heat pump observations from 13 manufacturers.

Static GitHub Pages model

This GitHub Pages version cannot run Python in the browser. Instead, it uses a precomputed grid of predictions generated from the same RandomForest_200t model used in the Streamlit app. Missing inputs broaden the comparison across the precomputed prediction grid.

Important: predictive fit is not causality. The model estimates associations learned from observed online product prices. It does not prove that changing one feature causes the price to change by a specific amount.

How the label is assigned

  • Cheaper than expected: offer price is more than 30% below the expected range.
  • In expected range: offer price is within the expected range.
  • Higher than expected: offer price is more than 30% above the expected range.

This is a research demo. It benchmarks product/configuration offer prices only and should not be used as a final purchasing recommendation.
